# 裏取り（ファクトチェック）の記録

2026-10-13 時点。誤りのリスクが高い 344問（法令・制度・技術規格・財務/統計）を対象に、一次資料との照合を試みた。1問ごとの記録は [`verification_log.csv`](verification_log.csv)。

## 確認の水準

| 水準 | 意味 | 件数の目安 |
|---|---|---|
| 一次資料で確認（条文） | e-Gov 法令検索の API で、条文の本文を取得して、問題の記述と照合した | 21問 |
| 一次資料で確認（公式ページ・PDF） | IPA の届出制度のページ、内閣府の「人間中心のAI社会原則」を取得して照合した | 8問 |
| 検算 | 稼働率・ROE・ROA・損益分岐点・順列などを、独立に計算して、正解と解説の数値が合うことを確認した | 約16問 |
| 一般知識で矛盾なし（一次資料は未取得） | 標準的な定義と矛盾しないことを確認したが、一次資料の本文は取得できていない | 上記以外の対象問題 |

**「確認済み」とは、一次資料の本文と照合できたものだけを指す**。「一般知識で矛盾なし」は、誤りが見つかっていないという意味で、裏付けとしては弱い。経済産業省・総務省・デジタル庁・金融庁・厚生労働省・国土交通省のサイトは、取得できない（403・404）ものが多かった。

## 一次資料で確認できた主な事項

- 著作権法 第51条（保護期間は著作者の死後70年）、第32条（引用の要件）
- 存続期間: 特許権は出願から20年（特許法第67条）、実用新案権は出願から10年（実用新案法第15条）、意匠権は出願から25年（意匠法第21条）、商標権は登録から10年（商標法第19条）
- 営業秘密の定義（不正競争防止法第2条第6項。秘密管理性・有用性・非公知性）
- 要配慮個人情報（個人情報保護法第2条第3項）、個人データの第三者提供には原則として本人の同意が必要（同法第27条）
- 不正アクセス行為の禁止（不正アクセス禁止法第3条）
- 労働者供給事業の禁止（職業安定法第44条）。二重派遣の禁止の根拠
- 人工知能関連技術の研究開発及び活用の推進に関する法律（AI基本法）、脱炭素成長型経済構造への円滑な移行の推進に関する法律（GX推進法）、特定電気通信による情報の流通によって発生する権利侵害等への対処に関する法律（情報流通プラットフォーム対処法）の正式名称と目的

## 裏取りで見つかり、修正したもの

- it_passport-0688: 問題文が「ウイルスや不正アクセスの被害」と両方を挙げていたが、IPAは別の制度で届出を受け付けているため、「コンピュータウイルスの被害」に絞った。
- it_passport-0814: 解説の「審査が簡易」を「実体審査を行わず、方式・基礎的要件の審査のみ」に直し、存続期間（出願から10年）を追記した。誤答の意匠権の存続期間は、出願から25年に直した。
